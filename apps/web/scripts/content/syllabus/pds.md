### Mô tả học phần

Học phần nhập môn về Python, ngôn ngữ lập trình được dùng nhiều nhất trong khoa học dữ liệu và phát triển phần mềm. Kết thúc học phần, người học có thể:

- hiểu và vận dụng các cấu trúc lập trình cốt lõi: biến, kiểu dữ liệu, cấu trúc điều khiển, hàm và lập trình hướng đối tượng;
- làm việc thành thạo với các thư viện NumPy và Pandas trong Jupyter Notebook;
- truy cập và lấy dữ liệu từ web bằng API và các công cụ scraping của Python như BeautifulSoup.

### Chuẩn đầu ra

**Kiến thức.** Nắm nền tảng lập trình Python gồm biến, kiểu dữ liệu, cấu trúc điều khiển, hàm và lập trình hướng đối tượng. Hiểu Python được dùng ra sao trong khoa học dữ liệu và phát triển phần mềm, và giúp xử lý, phân tích dữ liệu hiệu quả thế nào. Biết các thư viện thiết yếu NumPy và Pandas, và cách dùng Jupyter Notebook.

**Kỹ năng.** Viết được chương trình Python có cấu trúc theo cả hướng thủ tục lẫn hướng đối tượng. Làm việc thành thạo với dữ liệu số và dữ liệu dạng bảng bằng NumPy và Pandas, xử lý dữ liệu tương tác trong Jupyter Notebook. Truy cập nguồn dữ liệu trên web qua RESTful API và thu thập dữ liệu cơ bản bằng BeautifulSoup.

### Phương pháp giảng dạy

Học phần kết hợp trực tiếp và trực tuyến (blended learning):

- **Giảng dạy trực tiếp:** bài giảng của giảng viên và các buổi live coding giải thích cấu trúc lập trình cốt lõi và minh hoạ công cụ Python.
- **Thảo luận nhóm:** hoạt động cộng tác để cùng khám phá bài toán khoa học dữ liệu và chia sẻ cách giải.
- **Bài tập theo tình huống:** bài tập thực hành và dự án nhỏ dựa trên tình huống khoa học dữ liệu thực tế.
- **Thuyết trình cá nhân và nhóm:** trình bày lời giải, giải thích logic code và nhận phản hồi từ giảng viên và bạn học.
- **Tự học:** tài liệu đọc có hướng dẫn, hướng dẫn trực tuyến và notebook thực hành.
