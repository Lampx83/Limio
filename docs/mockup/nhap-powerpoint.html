Tạo bài giảng từ PowerPoint

Limio đọc từng slide của file, giữ chữ, hình và ghi chú giảng, rồi dựng lại bài theo giao diện Limio. Thiết kế gốc (màu, phông, hiệu ứng) không được sao chép.

1. Tải file PowerPoint

Nhận file .pptx. File .ppt đời cũ cần mở bằng PowerPoint rồi lưu lại thành .pptx. Bài trên Google Slides hoặc Keynote: tải xuống dạng PowerPoint (.pptx) rồi tải lên đây.

Kéo file .pptx vào đây hoặc Tối đa 50 MB. Hình trong file được tính vào dung lượng lưu trữ của thầy/cô.

  • Hiệu ứng chuyển động và phông chữ riêng của file không được chuyển.
